# KALM-NTG ARCHITECTS Website

Static HTML/CSS/JavaScript website for KALM-NTG ARCHITECTS.

## Main pages
- Home
- About
- Professional Services
- Construction Services
- Completed Projects
- Offices
- Diaspora Services
- Contact

The site is designed for static hosting such as GitHub Pages, Netlify or Cloudflare Pages.

### Contact form
Replace `YOUR_FORM_ID` in `assets/js/site.js` with a real Formspree form ID if you want server-side form handling. Until then, the form falls back to the visitor's email application.
